Privacy Policy

Zombie Shorts Uploader. Effective: 26 November 2026.

What the app accesses

With the permission of the signed-in account owner, the app uses Google OAuth to access that owner's YouTube channel through the YouTube Data API v3 (uploading videos, managing their playlists, thumbnails and comments) and the YouTube Analytics API (read-only statistics of the owner's own videos).

How the data is used

The data is used only to upload and schedule the owner's own videos and to read their statistics for the owner. The app does not access other users' accounts and is not offered to the public.

Storage

OAuth tokens and statistics are stored only on the owner's own computer. The app has no server and no database, and it does not send this data anywhere except to Google's APIs.

Sharing

No data is sold, shared with, or transferred to third parties, and none is used for advertising.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the app's local files removes all stored tokens and statistics.

Contact

Questions about this policy: open an issue in this site's GitHub repository.
